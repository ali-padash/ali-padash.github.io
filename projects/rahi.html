Rahi: Bus Ticket Reservation System

A bilingual (English / Persian) bus booking site with a Go API that can never sell the same seat twice. Built in 2024, reworked in 2026.

Overview

A practice project modelled on Safar724, an Iranian intercity bus booking site: search trips, pick seats on a drawing of the bus, enter passengers and receive a ticket. It is not affiliated with Safar724 and the payment page is a demo.

What I did

  • Layered Go REST API (Gin, GORM) on PostgreSQL with numbered SQL migrations; web, service and store layers that each only know the layer below.
  • No double sales: each booking runs in one transaction that locks the chosen seat rows in a fixed order (SELECT … FOR UPDATE) so bookings cannot deadlock, and a partial unique index makes the database itself refuse a second sale.
  • Seats are held for 10 minutes while the buyer reviews and pays, and released if they do not.
  • React + TypeScript frontend: search state in the URL, city autocomplete over 915 cities, seat maps drawn from each bus type's floor plan, and English (left-to-right) and Persian (right-to-left) with Persian digits and calendar. Checked at 360–480 px phone widths.
  • GitHub Actions CI and Docker Compose for the local database.

Results

  • Concurrency tests against a real PostgreSQL: 20 buyers request the same seat at the same moment and exactly one gets it.
  • 24 buyers with overlapping seat choices all finish without a deadlock.
