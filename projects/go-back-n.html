Reliable Data Transfer over UDP

The Go-Back-N sliding-window protocol over a deliberately unreliable channel, with CRC error detection and Hamming codes.

Overview

UDP delivers packets without guarantees. This project rebuilds reliable, in-order delivery on top of it and tests it against a simulated bad network.

What I did

  • Python sender and receiver over UDP sockets: 3-bit sequence numbers, a window of four frames, cumulative ACKs, and a timeout that resends the whole window (Go-Back-N).
  • CRC with the generator 10011 to detect corrupted frames, and a Hamming code to detect and correct single-bit errors.
  • Fault injection: 20% packet loss, 20% lost ACKs and a 1% bit-error rate, to check that the message still arrives intact and in order.
  • Threads and a lock so that sending, receiving ACKs and timers run concurrently.
