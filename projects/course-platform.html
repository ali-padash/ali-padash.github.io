Overview

The main project of Advanced Programming: a Quera-style learning platform built in stages, where each new project extended the previous code base with new requirements.

What I did

  • Sign-up and log-in with validated email and national code, and different rights for admins, normal users and guests.
  • Classrooms, public or password-protected, with exercises built from four question types (fill-in-the-blank, descriptive, short answer, multiple choice) and four difficulty levels; multiple-choice answers are corrected automatically.
  • Timed contests in three kinds (normal, private, special) with groups, invitations and member limits.
  • Scoreboards for exercises and contests, exported as HTML tables.
  • Final stage: everything admins and users create is saved to files with Java serialization and loaded again on the next start.
  • Built with Maven, with Checkstyle and PMD tests required by the course.
