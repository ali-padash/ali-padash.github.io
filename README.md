# ali-padash.github.io

Portfolio of Seyed Ali Padash Sotoodeh. Plain HTML and CSS, generated by one small Python script.

## Update a project

1. Edit `projects.json`. Each project has a `tier`:
   - `1`: featured, large card and its own page
   - `2`: course project, medium card and its own page
   - `3`: small, a row on the home page that expands in place
2. Put new images in `img/<project-slug>/` (WebP, about 1400 px wide).
3. Run `python build.py`. This regenerates `index.html` and `projects/*.html`.

Grades are shown only when they are 17 / 20 or higher.

## Files

| File | What it is |
|---|---|
| `projects.json` | All text: site info and the 20 projects |
| `build.py` | Generates the HTML (no dependencies beyond Python 3) |
| `style.css` | Layout, KNTU colours, light and dark theme |
| `theme.js` | Theme toggle and the bot-resistant email link |
| `diagrams/*.svg` | Hand-drawn diagrams, inlined into the pages so they follow the theme |
| `cv.pdf` | The CV behind the "Download CV" button (add your latest Europass export) |
| `PLAN.md` | The original plan and decisions |

## Publish on GitHub Pages

Create a public repository named `ali-padash.github.io`, push this folder's contents to its `main` branch, and the site appears at https://ali-padash.github.io.
